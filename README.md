VLSI Design Internship – Task 2

Introduction to Verilog HDL and RTL Design of Basic Combinational Circuits

This repository contains my solutions for Task 2 of the VLSI Design Internship. The objective of this task is to understand the fundamentals of Verilog HDL, RTL (Register Transfer Level) design, and implement basic combinational digital circuits.

Objectives

- Learn Verilog HDL syntax and module structure.
- Understand RTL design concepts.
- Implement basic logic gates using Verilog.
- Design Half Adder and Full Adder circuits.
- Write Verilog testbenches for verification.
- Simulate designs and analyze waveforms.

- Combinational Circuits
